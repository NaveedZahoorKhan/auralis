## 2024-11-20 - Adding Loading States to Async Buttons in Compose
**Learning:** During long-running tasks like importing large PDFs or downloading voice models in the Auralis app, standard Material buttons were remaining active without visual feedback, allowing users to queue up multiple conflicting operations.
**Action:** Always verify if an action triggers a background `suspend` task or WorkManager job. If so, add an `isBusy` flag to temporarily disable the interactive elements (`enabled = !isBusy`) and display a `CircularProgressIndicator` to improve affordance. Use string matching on transient statuses as a quick fallback if strongly typed UI states aren't available.
