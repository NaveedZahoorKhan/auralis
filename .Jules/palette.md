## 2023-10-27 - Add Loading Spinner to Async Button in Jetpack Compose
**Learning:** In Jetpack Compose, replacing static icons with `CircularProgressIndicator` during async operations (like audio generation) is a highly impactful micro-UX improvement. When embedding a progress indicator inside a `Button`, using the button's `onPrimary` color (e.g. `MaterialTheme.colorScheme.onPrimary`), a small size (`18.dp`), and adjusting the stroke width (`2.dp`) keeps the layout stable and the contrast accessible without visual jank.
**Action:** When finding async operations triggered by a button in Compose, check if the UI provides clear state feedback. If an icon remains static while text says "Loading...", swap the `Icon` for a `CircularProgressIndicator` sized to match the original icon.
